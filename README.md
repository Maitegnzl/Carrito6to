# Carrito de Compras - Proyecto

Pequeña aplicación web de carrito de compras construida con HTML, CSS y JavaScript puro.

## Características

- Vista de detalle del producto (modal).
- Agregar productos al carrito.
- Icono con notificación (badge) del número de productos en el carrito.
- Eliminar productos del carrito.
- Cálculo dinámico de subtotales y total.
- Persistencia usando `localStorage`.
- Mensaje de éxito al finalizar la compra.

## Tecnologías

- HTML5 semántico
- CSS3 (archivo `styles.css`)
- JavaScript (módulo `app.js`)
